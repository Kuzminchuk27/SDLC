## Описание

Настольное приложение для оператора платной автостоянки. Оператор регистрирует
въезд автомобиля (госномер, марка, время), при выезде программа рассчитывает
стоимость стоянки по тарифу, показывает свободные места и ведёт историю.

Требования изложены в файле `srs/srs.md`.

## Структура репозитория

- `project/` — проект для разработки (пока содержит заготовку из лабораторной работы № 2)
- `lab1/` — материалы лабораторной работы № 1 (ветка lab1)
- `srs/srs.md` — спецификация требований к «ПаркУчёт»
- `srs/images/` — макеты и диаграммы в формате PNG
- `srs/sysml/` — исходная модель на SysML v2 и скрипт отрисовки изображений
- `srs/`, `sdd/`, `adr/` — шаблоны проектной документации
- `docs/` — справочные материалы по стандартам

## Сборка

    cmake -S project -B build
