## Описание

Приложение с графическим интерфейсом пользователя для информирования
пользователя о нормальном артериальном давлении. Пользователь вводит свои
данные (возраст, вес, измеренное давление), программа рассчитывает
нормальное (идеальное) давление для его возраста и веса и сообщает,
является ли измеренное давление нормальным, повышенным или пониженным.

Архитектура построена по шаблону MVC с активной моделью: модель хранит
данные и выполняет расчёт, самостоятельно оповещая подписчиков об изменении
состояния; представление подписывается на модель напрямую; контроллер
обрабатывает действия пользователя.
