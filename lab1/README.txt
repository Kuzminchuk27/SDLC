Лабораторная работа №1 (ЖЦРПО), вариант 10
Утилита «Нормальное артериальное давление» — C++, WinAPI, MVC с активной моделью.

КАК ЗАПУСТИТЬ ГОТОВУЮ ПРОГРАММУ
  bin\PressureCalculator.exe — двойной щелчок, ничего устанавливать не нужно.

КАК ОТКРЫТЬ В VISUAL STUDIO (для показа преподавателю)
  1. Двойной щелчок по PressureCalculator.sln.
  2. Если VS предложит «Перенацелить проекты» (Retarget) — нажать ОК.
     (нужна рабочая нагрузка «Разработка классических приложений на C++»)
  3. Сверху выбрать Debug / x64, нажать F5 — программа соберётся и запустится.
  4. Отладка: щёлкнуть слева от номера строки (красная точка = точка останова),
     например в PressureModel::calculate (src\model\pressuremodel.cpp), нажать F5,
     ввести данные — выполнение остановится. F10 — шаг, F11 — шаг с заходом,
     внизу окна «Локальные» видны значения переменных.

КАК ОТКРЫТЬ В VS CODE (альтернатива)
  Открыть папку, установить расширения C/C++ и CMake Tools,
  выбрать компилятор (MSVC или MinGW) и нажать Build/Run — используется CMakeLists.txt.

СТРУКТУРА
  src\model\pressuremodel.*          — Модель (данные, проверка, расчёт, уведомления)
  src\view\mainwindow.*              — Представление: главное окно
  src\view\inputdialog.*             — Представление: окно ввода данных
  src\view\uihelpers.h               — вспомогательные функции интерфейса
  src\controller\pressurecontroller.* — Контроллер
  src\main.cpp                       — точка входа, связывание компонентов
